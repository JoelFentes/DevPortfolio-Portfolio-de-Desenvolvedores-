# 💼 DevPortfolio

**DevPortfolio** é uma aplicação web desenvolvida como projeto final para a disciplina de Programação Web no 4º período. O objetivo é criar um portfólio interativo onde desenvolvedores podem exibir suas habilidades, projetos e experiências, facilitando a conexão com empresas e recrutadores.

## 🚀 Tecnologias Utilizadas

- **Next.js** – Framework React para renderização do lado do servidor (SSR)
- **TypeScript** – Superset do JavaScript para maior segurança e escalabilidade
- **Tailwind CSS** – Framework utilitário para estilização rápida e responsiva
- **Prisma ORM** – ORM para interação com o banco de dados
- **SQLite/PostgreSQL** – Banco de dados relacional
